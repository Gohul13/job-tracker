JobTrack is a full-stack job application tracking web application built with the MERN stack.

It allows users to manage their job applications, track application status, search and filter applications, and view an overview of their job search through a dashboard.

🚀 Features

- 🔐 User Registration & Login
- 🔑 JWT-based Authentication
- 📊 Dashboard with application statistics
- ➕ Create job applications
- ✏️ Edit job applications
- 👁️ View application details
- 🗑️ Delete applications
- 🔎 Search applications by company or job title
- 🎯 Filter applications by status
- 💼 Filter applications by job type
- ↕️ Sort applications by date
- 📄 Pagination
- 🌙 Dark Mode
- 📱 Responsive UI
- 🔒 Protected routes
- ⚠️ Error handling

🛠️ Tech Stack

Frontend

- React

- Axios

Backend
